# 플로이드 워셜 알고리즘
**모든 노드에서 다른 모든 노드까지의 최단거리를 구할 때 사용하는 알고리즘**

## 점화식
```
D(a,b)​=min(D(a,b)​,D(a,1)​+D(1,b)​)
```

## 단계
1. 이차원 배열에 간선 하나만으로 갈 수 있는 모든 거리를 넣는다. (기본값 inf)
2. 점화식을 활용해서 1번 노드부터 차례로 값을 갱신한다.

## 구현
```python
n, m = map(int, input().split())

matrix = [[n]*n for _ in range(n)]        # INF를 n으로 표현했습니다.
                                          # 최단 거리는 노드의 개수보다 커질수 없기 때문입니다. 
for _ in range(m):
  a,b = map(int, input().split())
  matrix[a-1][b-1] = matrix[b-1][a-1] = 1 # 연결된 노드끼리의 거리는 모두 1입니다.
  										  # 무방향 그래프이므로 대각선 대칭으로 값을 입력합니다.
 
for i in range(n):
  matrix[i][i] = 0                        # 대각선을 0으로 초기화

for k in range(n):
  for i in range(n):
    for j in range(n):
      if matrix[i][j] > matrix[i][k] + matrix[k][j]:
        matrix[i][j] = matrix[i][k] + matrix[k][j]

result = []
for i in (matrix):
  result.append(sum(i))

print(result.index(min(result))+1)
```
