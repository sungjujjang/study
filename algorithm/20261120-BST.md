# BST
- BST : Binary Search Tree
- 이진 탐색 트리 : 정렬된 이진 트리
    - 노드의 왼쪽 서브트리에는 노드보다 작은 키만 존재
    - 노드의 오른쪽 서브트리에는 노드보다 큰 키만 존재
- 중복되는 수가 없다
- Inorder Traversal을 수행해 모든 키를 정렬된 순서로 가지고 올 수 있다.
    1. 왼쪽 자식을 꺼내기
    2. 부모 노드를 꺼내기
    3. 오른쪽 노드를 꺼내기
    4. 재귀적 호출
- 탐색에서 O(log N), 최악(불균형 상태)의 경우 O(N)

## 노드 삽입
1. ROOT에서 시작
2. 삽입 값을 루트와 비교
    - 루트보다 작으면 왼쪽으로 재귀
    - 루트보다 크면 오른쪽으로 재귀
3. 리프 노드에 도달했다면 노드에 따라 오른쪽/왼쪽으로 삽입

## 노드 삭제
1. 삭제할 노드가 리프 노드
    - 이 경우 노드를 삭제하기만 하면 됨
2. 삭제할 노드에 자식이 하나만 있는 경우
    - 노드를 삭제하고 삭제한 노드의 위치에 자식 노드를 삽입
3. 삭제할 노드에 자식이 둘 있는 경우
    - successor 노드를 찾아야 함
        - successor 노드 : inorder 순회에서 다음 노드
    1. 삭제할 노드를 찾기 (탐색)
    2. 삭제할 노드의 successor 노드를 찾기
    3. 삭제할 노드와 successor 노드의 값을 바꾸기
    4. successor 노드를 삭제
