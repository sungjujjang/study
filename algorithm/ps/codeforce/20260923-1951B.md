# CodeForce - 1951B
## B. 소 싸움 (Battle Cows)

Codeforces Round

코딩 토너먼트에 `n`마리의 소가 참가합니다. 소 `i`의 Cowdeforces 레이팅은 `aᵢ`이며, 모든 레이팅은 서로 다릅니다. 처음에는 소 `i`가 `i`번 위치에 있습니다.

토너먼트는 다음과 같이 총 `n−1`번의 경기를 진행합니다.

* 첫 번째 경기는 **1번 위치의 소와 2번 위치의 소**가 대결합니다.
* 이후 `i`번째 경기는 **`i+1`번 위치의 소와 이전 경기(`i−1`번째 경기)의 승자**가 대결합니다.
* 각 경기에서는 Cowdeforces 레이팅이 더 높은 소가 승리하여 다음 경기로 진출합니다.

당신은 `k`번 소의 주인입니다. 토너먼트에서 우승하는 것은 중요하지 않고, **당신의 소가 최대한 많은 경기에서 승리하기를 원합니다.**

토너먼트 주최자와 아는 사이이기 때문에, 당신은 **딱 한 번만** 당신의 소와 다른 소의 위치를 서로 바꾸도록 요청할 수 있습니다. 물론 **아무것도 하지 않아도 됩니다.**

위치를 최적으로 한 번 바꾸거나 그대로 두었을 때, `k`번 소가 얻을 수 있는 **최대 승리 횟수**를 구하세요.

## 입력

각 테스트에는 여러 개의 테스트 케이스가 주어집니다.

첫 번째 줄에는 테스트 케이스의 수 `t`가 주어집니다.

각 테스트 케이스의 첫 번째 줄에는 두 정수 `n`, `k`가 주어집니다.

* `n`: 소의 수
* `k`: 당신의 소의 번호
* `2 ≤ n ≤ 10⁵`
* `1 ≤ k ≤ n`

두 번째 줄에는 `n`개의 정수 `a₁, a₂, …, aₙ`이 주어집니다.

* `aᵢ`: `i`번 소의 Cowdeforces 레이팅
* `1 ≤ aᵢ ≤ 10⁹`
* 모든 `aᵢ`는 서로 다릅니다.

모든 테스트 케이스에서 `n`의 합은 `10⁵`을 넘지 않습니다.

## 출력

각 테스트 케이스마다, 위치를 최적으로 한 번 바꾸거나 아무것도 하지 않았을 때 `k`번 소가 얻을 수 있는 **최대 승리 횟수**를 출력합니다.

## 예제

### 입력

```text
3
6 1
12 10 14 11 8 3
6 5
7 2 727 10 12 13
2 2
1000000000 1
```

### 출력

```text
1
2
0
```

## 정답 코드
```python
def simulate(a, k, pos):
    arr = a[:]

    arr[k], arr[pos] = arr[pos], arr[k]

    winner = 0

    wins = 0

    for i in range(1, len(arr)):
        if arr[i] > arr[winner]:
            winner = i

        if winner == pos:
            wins += 1

    return wins


t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    k -= 1

    a = list(map(int, input().split()))

    x = a[k]

    ans = simulate(a, k, k)

    ans = max(ans, simulate(a, k, 0))

    for i in range(n):
        if a[i] > x:
            ans = max(ans, simulate(a, k, i))
            break

    print(ans)
```

## 풀이
- 소를 옮겨 볼 후보가 3개 뿐이다
  - 가만히 있는 경우
  - 맨 앞으로 가는 경우
  - 나보다 큰 소가 처음 등장하는 위치로 가는 경우
- 나보다 큰 소를 피하려면
  - 처음 만나는 큰 소를 이용해서 위치를 바꾸는 경우를 보면 됨
- 앞쪽으로 옮길 거면
  - 아예 맨 앞이 가장 많은 작은 소를 만날 수 있음
  
### 실패 시도 1
- 전체를 모두 훑으면 되지 않을까?
- 완전 탐색으로 전 경우를 모두 탐색했다.
  - O(n^2)으로 시간 초과
