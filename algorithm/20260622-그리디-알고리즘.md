# 그리디 알고리즘
각각의 선택 상황에서 최적의 해를 구하는 알고리즘

→ 전체적으로 보았을 때는 최적의 해가 아닐 수 있다.

→ dp나 완탐 알고리즘으로 풀어야 함

그리디 알고리즘의 성립 조건

1. 탐욕적 선택 속성
    1. 앞의 속성이 이후의 선택에 영향을 주지 않아야 함
2. 최적 부분 구조
    1. 문제의 최종 해는 부분 문제로 나누어저야 함

그리디가 실패하는 경우

동전 단위가 500, 400, 100인데 800을 거슬러 주어야 한다면?

800/500 + 300/100 = 4 보다

800/400 = 2 가 더 작으므로

동전이 배수 관계가 아닐 경우 실패한다.
