# 스레드
- 프로세스 내부에서 실행되는 작은 작업 단위
- 하나의 프로세스 <-> 여러 스레드

## 특징
- 프로세스의 데이터 영역에 접근이 가능하다.
- 스레드끼리 서로의 데이터에 접근 가능하다.
- 스레드도 프로세스처럼 병렬 처리가 가능하다.
- 스레드는 thread stack이라는 메모리 공간만 갖는다.
- 일종의 함수로 구현된다.
- **하나의 스레드에 문제가 발생하면 다른 스레드에서도 문제가 발생 가능하니 주의해야 한다.**

## 장점
- 응답성(성능) 향상
    - 빠른 결과 제공
- 자원 공유 효율성 향상
- 동시성
    - 작업 병렬 처리
- 간결성
    - 작업을 분리해 코드 간결

## 단점
- 스레드 간 상호 간섭
- 성능 저하
    - 스레드 많이 생성 시 각각의 스레드들이 병렬로 실행되기 위해 컨텍스트 스위칭이 빈번하게 발생해 성능이 저하될 수 있음
