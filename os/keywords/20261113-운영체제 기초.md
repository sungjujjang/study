# 운영체제 기초

## 운영체제 역할
- 자원 관리
  - 컴퓨터 시스템의 자원을 효율적으로 관리
  - (자원: CPU, MEMORY, I/O 장치와 같은 하드웨어 자원과 프로세스, 파일 메시지 등의 소프트웨어 자원)
- 자원 보호
  - 프로그램이나 다른 사용자가 데이터를 삭제하거나 중요 파일에 접근하지 못하게 컴퓨터 자원들을 보호
- 인터페이스 제공
  - 하드웨어 인터페이스와 사용자 인터페이스 제공하며 편리하게 사용하도록 지원

## 운영체제 목적
- 응답 시간
  - 작업 의뢰 후 시스템에서 결과가 얻어질 때까지의 시간
- 처리 능력
  - 일정 시간 동안 처리하는 일의 양
- 사용 가능도
  - 시스템을 얼마나 빠르게 사용할 수 있는가의 정도
- 신뢰도
  - 주어진 문제를 얼마나 정확하게 처리하는가의 정도

## 커널
- 운영체제 중 항상 메모리에 올라가 있는 운영체제의 핵심 부분
- 하드웨어, 응용 프로그램 사이에서 인터페이스 제공
- 컴퓨터 자원들을 관리
- but, 커널은 컴퓨터 자원들을 바라만 보고 있음
  - 사용자와의 상호작용을 위해 대표적으로 쉘이라는 명령어 해석 프로그램을 사용한다.

## 시스템 콜
- 프로그램이 OS의 기능을 사용하기 위해 커널에 요청을 보내는 인터페이스
  - 사용자 프로그램이 운영체제에게 특정 작업을 대신 처리해달라고 요청하는 것
- 컴퓨터에서는 프로그램이 마음대로 하드웨어나 시스템 자원에 접근 불가능(운영체제가 자원 관리)
- 따라서 아래 작업은 운영체제의 도움이 필요
  - 파일 읽기 및 쓰기
  - 프로세스 생성 및 종료
  - 메모리 할당
  - 네트워크 통신
  - 입출력 장치 접근
- 동작 과정
  1. 사용자 프로그램이 커널에 시스템 콜
  2. 커널이 파일 시스템을 통해 읽기 처리 후 처리 결과 반환
  3. 사용자 프로그램은 반환된 데이터를 사용

## 운영체제 모드

### 커널 모드
- 운영체제의 핵심 부분이 커널이 실행되는 모드
- CPU에게 가장 높은 실행 권한 부여
- 하드웨어 자원에 직접 접근 가능, 하드웨어 자원 직접 관리 가능
- 모든 종류의 명령을 다 수행 가능

### 사용자 모드
- 어플리케이션 등 사용자 프로그램이 실행되는 모드
- CPU에게 가장 낮은 실행 권한을 부여하는 모드
- 제한적인 명령만 수행 가능

### 사용자 모드에서 커널 모드로 진입하는 경우
- Exception 발생
  - 사용자 프로세스에서 오류 발생 시 CPU는 해당 예외 처리를 위해 커널 모드로 진입
- 인터럽트 발생
  - 인터럽트 발생 시 중단 후 인터럽트 핸들러 함수 실행을 통해 인터럽트 처리
  - 처리가 완료된 이후에는 다시 원래 작업으로 복귀

### ModeBit
- CPU가 현재 어떤 권한으로 실행되고 있는 지를 나타내는 비트
- 사용자 모드와 커널 모드를 구분하기 위해 사용
  - `0`: 커널 모드
  - `1`: 유저 모드
- 동작 방식
  1. 유저 모드에서 일반 프로그램 실행 (modebit: 1)
  2. 시스템 콜 실행 (modebit: 0)
  3. 커널 모드에서 작업 수행 (modebit: 0)
  4. 작업 완료 후 복귀 (modebit: 1)

## 부팅
- 컴퓨터 시스템이 켜질 떄 운영체제를 로드하여 실행 가능한 상태로 만드는 과정

### 종류
- Cold Boot
  - 컴퓨터 전원을 처음 켜는 과정
  - 하드웨어 초기화 후 운영체제 로드
- Warm Boot
  - 시스템이 이미 실행 중일 때 재부팅을 수행하는 과정
  - 하드웨어 초기화 과정 생략 가능

### 과정
1. 전원 공급 및 하드웨어 초기화
  - 컴퓨터에 전원 공급 시 CPU는 하드웨어 초기화
  - POST (Power On Self Test)
    - 하드웨어 테스트 수행
    - CPU, 메모리, 키보드, 디스크 드라이브 등이 정상 작동하는지 점검
    - 문제 발생시 비프음 (삐삐 거리는거) 또는 화면 메시지로 알림
2. 부트로더 실행 준비
  - BIOS/UEFI 실행
    - BIOS 또는 UFEI가 ROM에 저장된 상태에서 실행
      - 펌웨어, 하드웨어 초기화나 부팅할 장치를 찾는 등의 역할을 수행
      - UEFI가 최신 버전, GPT 지원, Secure Boot 등의 기능을 제공
    - 하드웨어와 소프트웨어 간 인터페이스 역할 수행
    - 저장 장치에서 운영체제를 로드할 디바이스 결정
  - MBR/GPT(디스크에 파티션 정보를 저장하는 방식) 확인
    - 부팅 가능한 디스크(MBR or GPT) 확인
      - BIOS + MBR : MBR에 작은 부팅 코드, 이를 통해 추가 부트로드 코드 실행
      - UEFI + GPT : GPT 자체에 부트로더가 들어간 것이 아님, UEFI가 EFI 시스템 파티션(ESP)에 있는 .efi 부트로더 파일을 실행
3. 부트로더 실행
  - 부트로더
    - 운영체제를 메모리에 로드, 제어를 넘기는 역할을 담당
    - GRUD(Linux), NTLDR(Windows), BOOTMGR(Windows)
    - 1단계 부트로더
      - BIOS/UEFI에서 로드, 운영체제가 저장된 파티션과 2단계 부트로더를 식별
    - 2단계 부트로더
      - 운영체제 로드
      - 운영체제의 커널을 메모리에 복사한 후 실행 시작
4. 커널 로드
  - 부트로더가 선택한 운영체제의 커널을 메모리에 로드
  - 초기화 작업
    - CPU 및 메모리 구성
    - 디바이스 드라이버 로드
    - 프로세스 관리 준비
5. 사용자 공간 초기화
  - 커널이 초기화 될 시 사용자 공간 프로그램을 실행
  - Init System(Linux)또는 Windows Session Manager가 시작
    - init: 리눅스에서 사용되는 프로세스 관리 시스템 (ex: systemd)
    - Windows: `wininit.exe` 사용
  - 사용자 로그인 화면 또는 GUI 환경 제공
