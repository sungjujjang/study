# PTY

## TTY

TTY (Teletypewriter)는 리눅스 환경에서 터미널 화면을 그리는 곳이다.

터미널과 프로세스 사이의 입출력을 담당한다.

예시

`Keyboard - 터미널 - TTY - bash`

## PTY

PTY (Pseudo Terminal)는 가상 터미널이다.

실제 물리적인 터미널이 없어도 진짜 터미널이 있는 것처럼 만들어 주는 것이다.

### PTY 구조

```
PTY
├── PTY Master -> Program
└── PTY Slave -> bash
```

### PTY Slave

프로세스 입장에서 터미널처럼 보이는 곳이다.

예시

`bash 프로세스 -> /dev/pts/0`

### PTY Master

외부 프로그램이 Master를 통해 데이터를 보내거나 읽는다.

예시

`외부 프로그램 -> PTY Master -> PTY Slave -> bash`

# Linux - Everything is a file

프로그램의 입출력은 기본적으로 파일 디스크립터를 사용한다.

## 기본 파일 디스크립터 3개

- `0` -> stdin (표준 입력)
- `1` -> stdout (표준 출력)
- `2` -> stderr (표준 에러)

프로세스가 파일을 다룰 때 사용하는 개념이다.

파일 디스크립터는 열린 입출력 대상에 접근하기 위한 식별 번호다.

기본 3개는 표준 입출력을 위한 식별 번호다.

파일을 열면 `3`, `4` 등의 번호가 추가로 할당된다.

파일 디스크립터는 파일, 터미널 입출력, 파이프, 소켓 등을 다룰 때 사용한다.

## Bash 프로세스의 파일 디스크립터

Bash 프로세스가 PTY Slave에 연결되어 있다면 다음과 같은 구조가 된다.

```
Bash Process
├── 0: /dev/pts/3
├── 1: /dev/pts/3
└── 2: /dev/pts/3
```

위 세 파일 디스크립터는 모두 PTY Slave에 연결되어 있다.
