# 1. 데이터베이스
- 특정 조직의 여러 사용자가 공유해서 사용할 수 있도록 통합해서 저장한 운영 데이터의 집합
  - 여러 사람이 함께 공유
  - 모든 데이터가 통합되어서 중복이 최소화되도록 함
  - 컴퓨터의 데이터 형식으로 저장된다
  - 조직의 주요 기능을 수행하기 위한 필수 데이터

## 데이터베이스의 특징
- 실시간 접근
  - 데이터베이스는 사용자의 데이터 요구에 실시간으로 응답할 수 있어야 한다.
- 게속 변화한다
  - 데이터베이스는 동적인 특징이 있어 데이터를 계속 삽입/삭제/수정하여 현재의 정확한 데이터를 유지해야 한다.
- 동시 공유가 가능하다.
  - 동시 공유는 여러 사용자가 서로 다른 데이터를 동시에 사용하는 것뿐 아니라, 같은 데이터를 동시에 사용하는 것도 모두 지원한다는 의미다.
- 내용으로 참조가 가능하다.
  - 데이터베이스는 저장된 주소나 위치가 아닌 데이터의 내용, 즉 값으로 참조할 수 있다.

## 데이터의 종류
- 정형 데이터
  - 정해진 구조가 있는 데이터이다.
  - 예시) 스프레드시트
- 반정형 데이터
  - 구조가 정해져 있지만 구조에 대한 설명이 존재한다
  - 읽기 위해서 파싱 등의 추가 작업이 필요하다.
- 비정형 데이터
  - 정해져 있지 않은 데이터이다.
