# 교차 검증과 그리드 서치

검증 세트

테스트 세트를 사용하지 않으면 모델의 과소적합과 과대적합 여부를 판단하기 어렵다. 따라서 훈련 세트, 검증 세트, 테스트 세트로 데이터를 나눈다.

훈련 세트는 60퍼센트, 검증 세트는 20퍼센트, 테스트 세트는 20퍼센트로 구성할 수 있다.

훈련 세트가 많으면 모델 학습에 도움이 된다. 검증 세트는 모델의 성능을 평가하고 하이퍼파라미터를 조정하는 데 사용한다.

교차 검증

검증 세트를 여러 번 바꾸어 가며 모델을 평가하는 방법이다.

훈련 데이터를 여러 부분으로 나누고, 그중 한 부분을 검증에 사용하며 나머지를 훈련에 사용한다. 이 과정을 반복하여 여러 번 평가한 결과를 평균 내어 최종 성능을 판단한다.

K Fold 교차 검증

데이터를 K개의 폴드로 나눈다. 각 폴드를 한 번씩 검증 세트로 사용하고 나머지는 훈련 세트로 사용한다.

모든 폴드의 평가 결과를 평균 내어 모델의 성능을 평가한다.

하이퍼파라미터 튜닝

하이퍼파라미터는 모델이 학습 과정에서 스스로 결정하지 못하므로 사용자가 지정해야 하는 설정값이다.

자동 하이퍼파라미터 튜닝에는 AutoML 등을 사용할 수 있다.

최적의 하이퍼파라미터를 찾는 방법으로 그리드 서치와 랜덤 서치가 있다.

그리드 서치

1. 탐색할 하이퍼파라미터와 각 매개변수의 후보값을 지정한다.
2. 훈련 세트와 검증 방법을 이용해 모든 매개변수 조합을 평가한다.
3. 가장 좋은 성능을 보이는 매개변수 조합을 선택한다.
4. 선택한 최적의 매개변수로 최종 모델을 훈련한다.

랜덤 서치

매개변수의 값을 하나씩 정하기 어렵거나 탐색할 조합이 너무 많을 때 사용한다.

매개변수별로 설정한 범위나 확률분포에서 값을 무작위로 추출하여 일부 조합만 평가한다.

그리드 서치보다 적은 횟수로 다양한 매개변수 조합을 탐색할 수 있다.
