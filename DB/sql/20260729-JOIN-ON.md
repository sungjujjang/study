# JOIN ON

## ON 이란?
- JOIN 시에 어떤 기준으로 JOIN 할 것인지 정하는 것 
```sql
SELECT *
FROM post p
JOIN user u
ON p.user_id = u.id;
```
- 조건을 여러 개 이어서 붙일 수 있다
```sql
ON p.user_id = u.id
AND u.deleted = false
```
- `p.user_id = u.id` 위 조건을 만족하는 것들을 JOIN홤

## WHERE VS ON
= WHERE
  - JOIN 된 이후 필터링하는 것
- ON
  - JOIN 될 떄 조건을 붙이는 것
