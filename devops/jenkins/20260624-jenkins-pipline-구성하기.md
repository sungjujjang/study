# 젠킨스 파이프라인 구성하기
## Github Poll
- 일정 주기마다 깃허브에 Poll을 하여 상태를 받아오는 방식.
- 주기가 짧을수록 서버 부하가 커진다는 단점이 있다.

## Github Webhook
- push마다 깃허브에서 서버측으로 Webhook을 전송하도록 한다.
- 깃허브 서버 상태에 따라 시간이 오래 걸릴 수 있다는 단점이 있다.

## 파이프라인 구성
- 도커 빌드를 사용하려고 했으나, Docker In Docker 방식에 문제가 있다고 판단함.
	- Kaniko를 사용하여 빌드하고 Docker Hub에 업로드함.
- Github Personal Token을 발급받아 Gitops 레포지토리를 수정하는 데에 사용함.
- GitOps 레포지토리에 이미지 버전을 수정하고 푸시하는 방식으로 CD를 Sync시킴.

## Branch 구성
- 브랜치를 파이프라인에서 구성함.
- **브랜치는 파이프라인에서 설정 후 빌드를 한 번 이상 돌려야 함**
