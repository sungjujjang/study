# MetalLB 아이피 할당 문제
- 학교 와이파이를 쓰니 대역에 문제가 생김
	- 핫스팟으로 번경해서 사용함
- 핫스팟은 일반 네트워크와 다르게 대역이 0.0.0.0/28 이다.
```
network  : 172.20.10.0
broadcast: 172.20.10.15
hosts    : 172.20.10.1 ~ 14
```
- 사용할 수 있는 대역이 1~14까지이다.

## ARP 문제
- MetalLB는 ARP 방식을 사용한다.
- 대역을 정해놓으면, 스피커들이 맥 주소를 보내는 방식으로 L2 스위치를 구현한다.
- 하지막 대역이 다르거나 맞지 않으면 arp를 보내도 의미가 없으므로 대역을 잘 설정해야한다.
