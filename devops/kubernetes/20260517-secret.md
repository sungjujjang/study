# 시크릿
- 쿠버네티스에서 api 키와 같은 민감한 정보들을 관리하는 방식
```
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque # 일반적인 키-값 쌍을 저장할 때 사용
data:
  # 주의: 값들은 반드시 Base64로 인코딩되어 있어야 합니다.
  # 예: echo -n 'root' | base64 -> cm9vdA==
  DB_USER: cm9vdA==
  DB_PASSWORD: bXlfc3Ryb25nX3Bhc3N3b3JkCg==
```
- data 밑으로 저장하며, **Base64로 인코딩 되어 있어야 함**
```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: backend-api
spec:
  template:
    spec:
      containers:
      - name: app
        image: my-backend:v1
        env:
        - name: DATABASE_USER         # 프레임워크가 인식할 환경변수 이름
          valueFrom:
            secretKeyRef:
              name: db-secret         # 우리가 만든 Secret 이름
              key: DB_USER            # Secret 안의 키
        - name: DATABASE_PASSWORD
          valueFrom:
            secretKeyRef:
              name: db-secret
              key: DB_PASSWORD
```
- Deploy 시에 시크릿 키를 주입한다(환경 변수와 같은 개념)
```
// 쿠버네티스가 주입해준 환경변수를 그대로 읽음
const dbUser = process.env.DATABASE_USER;
const dbPassword = process.env.DATABASE_PASSWORD;
```
```
spring:
  datasource:
    username: ${DATABASE_USER}      # OS 환경변수를 스프링이 자동으로 매핑
    password: ${DATABASE_PASSWORD}
```
