# 역할기반 접근제어 (RABC)
- 누가 무엇을 어디서 제한하는지 설정하기
- Yaml 파일로 Role 생성

## Role vs ClusterRole
- Role
	- 특정 NameSpace에서만 적용
- ClusterRole
	- 전체 NameSpace에 적용

## 왜 쓰는가
- 보안적 측면에서 다 열어놓게 되면 절대 안됨
- 실무에서 dev, prod, stage 다 따로 관리하는데 실수로 dev 건드리려다 prod 건드리는 사태 막기 위함

## 멀티 테넌시
- 하나의 인프라를 여러 개로 쪼개서 사용하는 법
- 네임스페이스로 여러 개 나누어서
- 여러 클러스터를 쓰는 것 보다
	- 비용면에서 줄고
	- 안정(운용성) 면에서 좋다
