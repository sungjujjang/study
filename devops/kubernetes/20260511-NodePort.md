# 노드포트
- 외부에서 내부로 접속하는 방식
- 외부(30080번 포트) <-> 내부 파드(80번 포트)
- 서비스로 관리됨

## Kube-proxy
- k8s의 모든 네트워크 트래픽을 처리
- 따라서 kube-proxy를 통해 외부 어느 노드의 아이피로 접속해도 부하가 분산됨
```
========================================
추출된 내부 IP (10.x.x.x:port)      | 횟수
----------------------------------------
10.72.128.34:80                    | 22회
10.72.130.29:80                    | 21회
10.72.129.22:80                    | 21회
10.72.128.28:80                    | 18회
10.72.130.30:80                    | 18회
=========================================
```
- 위와 같이 5개의 파드에 골고루 분산되는 것을 알 수 있음
	- `부하분산 테스트.py`
## 단점
- 실제로는 30000~ 부터 포트를 할당시킬 수 있음
- 따라서 80, 443 등의 포트를 사용하기 위해서는 로드밸런싱을 주로 씀
