# 프로메테우스
- 데이터 수집, 데이터 저장, 알림 등의 기능을 가지고 있음
- 시계열 데이터베이스에 직접 저장

# 그라파나
- 프로메테우스 등에서 수집한 데이터를 시각화함
- 대시보드를 통해 시각화된 데이터를 확인 가능

## 프로메테우스 스택
- 프로메테우스, 얼릿메니터(알림), 그라파나 등을 다 따로 설치하면 시간이 오래 걸림
- 한번에 점마들 다 설치해주는 것

## 로키
- 쿠버네티스 로그 솔루션
- 파드, 서비스 등의 로그를 수집해서 그라파나에서 바로 볼 수 있게 함

### 네임스페이스 분리
- 그라파나를 각각의 네임스페이스에 따로 띄워 그 네임스페이스의 로그, 사용량 등을 볼 수 있게 하는 법
