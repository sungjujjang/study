# 01-02. 네트워크 모델

## 1) 프로토콜 계층화

- **프로토콜에서 각 계층의 기능들을 수행하는 주체**: 엔터티(Entity)
- **임의의 계층과 하위 계층이 서비스를 주고받는 규약**: 인터페이스(Interface)
- **멀리 떨어진 송/수신측이 동일 계층 간 통신**: 대등-대-대등 프로세스(Peer-to-Peer Process)

### EX)
- 언어층: 한국어 ↔ 한국어
- 통신 장치층: 무전기 ↔ 무전기
- 같은 계층끼리는 **프로토콜**을 사용
- 인접 계층끼리는 **인터페이스**를 사용

## 2) OSI 참조 모델

- **7계층의 개방 시스템 모델**
  - 물리
  - 데이터링크
  - 네트워크
  - 전송
  - 세션
  - 표현
  - 응용

- **전송**: 상위 계층에서 받은 메시지에 본 계층 정보를 저장 → 아래 계층으로
- **송신**: 전송의 반대로 **언패킹(Un-Packing)**을 함

## 3) TCP/IP

- OSI 모델이 완전히 구현되지는 않았기 때문에 **TCP/IP 프로토콜**을 사용
- TCP/IP 계층
  - 물리
  - 데이터링크
  - 네트워크
  - 전송
  - 응용

- OSI 모델과 동일한 계층이 존재
- **최상위 3계층이 통합됨**

### 주요 프로토콜
- 네트워크 계층 → **IP**
- 전송 계층 → **TCP**
