## 2) 오류보고 메시지

목적지 도달 불가

라우터나 호스트가 데이터그램 전달 불가시 폐기와 함께 ICMP 패킷 전송

목적지 도달 불가 패킷이 안 왔더라도 전송하게 알려 X

발신지 억제

혼잡으로 인해 데이터그램 폐기시 억제 메시지 전송
ex. 버퍼오버플로우

시간 경과

TTL 만료로 폐기시 메시지 전송

매개변수 문제

데이터그램 필드에서 불량값 / 빠진 값 발견시 메시지 전송

재지정

host의 라우팅 테이블 갱신 필요시 메시지 전송
